Reference Image

CLICK HERE for usage description

The reference image is the base image on which the alignment marker, digit ROIs and analog ROIs will be defined. It only serves the need to have a visual feedback while defining alignment marker and ROIs. It is not used for any cycle processing task.

If you start with the setup from scratch no reference image is available and only a textual info is shown. Otherwise the actual saved reference image is shown. Use the button "Create New Reference" to start creating your own reference image. After selecting the button a new image will be taken using all configured parameter. With the button "Update Image" the image can be refreshed (still all parameter get applied to the new image).

To have reliable evaluation processing a properly horizontal aligned evaluation area is mandatory. Using the parameter "Image Rotation" the image can be rotated in both directions. The resulting rotation angle is used to pre-rotate the image before the alignment algorithm is processed to compensate only small misalignments of rotation or shift.

Setup helpers (added in this modified version), step by step:
1. "Draw Line": click where the first digit starts, then where the last digit ends. The image is rotated so the digits are horizontal; the click order sets the reading direction. "Rotate 180°" turns the image upside down if needed.
2. "Draw Box": click two opposite corners of a box tightly around the digits.
3. "Auto-level": fine-tunes the rotation within 5° so the edges in the box are exactly horizontal. Without a box it tries to find the digit band itself; this works only for some meter types.
4. "Auto-Tune Image": takes several test images and keeps the flash intensity, brightness and contrast that make the box content most readable.

After setting up your reference image don't forget to save the new configuration with the button "Save And Apply". The new configuration gets automatically applied. No reboot is required.
