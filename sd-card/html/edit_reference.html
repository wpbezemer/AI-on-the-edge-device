📸Reference Image
CLICK HERE for usage info

The reference image serves as the visual base for defining markers and ROIs; it provides feedback during setup but is not used in live processing. Click Create New Image to capture one using your current settings, or use Update Image to refresh it.
For reliable evaluation, ensure the image is horizontally aligned. Use the 'Image Rotation' parameter to pre-rotate the image, which allows the alignment algorithm to focus solely on correcting minor shifts.

Setup helpers, step by step:
1. Draw Line (below 'Image Rotation'): click where the first digit starts, then where the last digit ends. The image is rotated so the digits are horizontal; the click order sets the reading direction. Rotate 180° turns the image upside down if needed.
2. Draw Box: click two opposite corners of a box around everything that has to be read (digits and dials).
3. Zoom To Box (below 'Zoom Offset Y'), optional: sets zoom factor and offsets so the box fills the image and takes a new image. Reset Zoom goes back to 1.00x.
4. Auto-Tune Image: takes several test images and keeps the flash intensity, brightness and contrast that make the chosen area most readable: the box, or the whole image (selection next to the button, remembered in this browser).

Once satisfied, click Save And Apply to activate your configuration immediately without a reboot.
