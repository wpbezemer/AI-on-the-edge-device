The reference image is the base image on which the alignment marker, digit ROIs and analog ROIs will be defined. It only serves the need to have a visual feedback while defining alignment marker and ROIs. It is not used for any cycle processing task.

If you start with the setup from scratch no reference image is available and only a textual info is shown. Otherwise the actual saved reference image is shown. Use "New image" above the image to start creating your own reference image. After selecting the button a new image will be taken using all configured parameter. With the button "Take new image" the image can be refreshed (still all parameter get applied to the new image).

To have reliable evaluation processing a properly horizontal aligned evaluation area is mandatory. Using the parameter "Image Rotation" the image can be rotated in both directions. The resulting rotation angle is used to pre-rotate the image before the alignment algorithm is processed to compensate only small misalignments of rotation or shift.

Setup helpers (added in this modified version):
1. Align: use Draw line under the image: click where the first digit starts, then where the last digit ends. The image is rotated so the digits are horizontal; the click order sets the reading direction. Rotate 180° turns it upside down if needed.
2. Draw box under the image: click two opposite corners. Zoom to box sets zoom factor and offsets so the box fills the image (draw the box around everything that has to be read, digits and dials: anything outside is cut off). Reset zoom goes back to 1.00x.
3. Auto-tune takes 7 test images and keeps the flash intensity, brightness and contrast that make the Box (or the Whole image) most readable.
Discard goes back to the last saved settings and reference image. Nothing is stored before Save And Apply.

After setting up your reference image don't forget to save the new configuration with the button "Save And Apply". The new configuration gets automatically applied. No reboot is required.
